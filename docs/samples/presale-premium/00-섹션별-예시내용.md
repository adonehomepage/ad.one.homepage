# 프리미엄 화보형 — 섹션별 예시 내용 · 소스 이미지

- 템플릿 코드: `foreon` (표시명: 분양 현장형 / 프리미엄 화보 스킨)
- 예시 카피: 가상 현장 `노을정원 하버포레` (경기도 시흥시 배곧동 256, 031-000-1800)
- 예시 이미지: 프리미엄 화보형 샘플 팩 (사진 파일은 유지)
- Adit 경로: `public/samples/presale-premium/`, `src/modules/templates/definitions.ts` (`sampleByType`)
- **제외:** WHY 직방·호갱노노, 담당상담사, FAQ(출시 범위 밖). 원본 폴더에 있어도 Adit에는 넣지 않는다.

> 아래 텍스트·이미지는 **제작 시 교체용 샘플**입니다. 실제 현장 정보로 바꿔 주세요.

---

## 공통 섹션 순서 (Adit)

```
hero → overview → location → premium → floorplan
→ lead_form → directions → legal
```

`lead_form`의 스크롤·GNB 앵커는 `inquiry` (`#inquiry`)이다.

(+ GNB, 푸터, 선택 이벤트 팝업)

- 현장명: `노을정원 하버포레`

- 현장명·전화 동일
